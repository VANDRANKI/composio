# Recommended .gitignore additions for Composio SDK development

Add these patterns to the root `.gitignore` to avoid committing generated
or local-only files during TypeScript and Python SDK development.

## TypeScript / Node.js
```
# pnpm
.pnpm-store/

# Turbo cache
.turbo/

# Build outputs
dist/
build/
*.tsbuildinfo

# Test output
coverage/
.nyc_output/
test-results/
playwright-report/

# Editor
.vscode/
.idea/
*.swp
```

## Python
```
# Virtualenvs
.venv/
.uv/
.hatch/

# Caches
.ruff_cache/
.mypy_cache/
.pytest_cache/
htmlcov/
coverage.xml

# Build
dist/
*.egg-info/
```

## Common
```
# Secrets
.env
.env.local
.env.test

# OS
.DS_Store
Thumbs.db

# Logs
*.log
logs/
```
